These files are generated by `generate.sh` and mirror a PKIoverheid G4 UZI server certificate chain
(RSA 4096, RSASSA-PSS/SHA-512, UZI otherName and permanentIdentifier SANs).

The issuing CA is used as did:x509 ca-fingerprint. After regenerating, update the fingerprint in
`../discovery.json`, `../accesspolicy.json` (the script prints it) and the CA subject DN in `../run-test.sh` if it changed.
